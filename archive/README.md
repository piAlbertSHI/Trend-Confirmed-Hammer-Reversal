# Archive

This directory preserves source materials used to reconstruct the TCHR study.

- `source/` contains selected historical R scripts.
- `drafts/` contains research variants retained for provenance.
- `replay.R` and `replay.rds` support the historical reconstruction checks.
- The extended OHLC input used by the fixed study is stored in `data/raw/HSI_extension.json`.

The current public presentation uses the TCHR fixed window from 2001-03-01 to 2025-05-30. Earlier generated display pages and figures remain available in older Git commits.
