# Archive

This directory preserves source materials used to reconstruct the TCHR study.

- original-report.docx is the original research report.
- source/ contains the selected historical R scripts.
- drafts/ contains deduplicated research variants.
- legacy-display/ contains the earlier expanded report, results, figures, and supplemental input data.

The current public presentation uses the TCHR fixed window from 2001-03-01 to 2025-05-30. Archived materials are retained for provenance and reproducibility.
